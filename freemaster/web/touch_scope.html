S32K144W Capacitive Touch Sensing Reference Implementation (CVD & Rule-Based Classifier)

An embedded capacitive touch sensing firmware reference implementation designed for the NXP Semiconductors® S32K144W evaluation board (XS32K14WEVB-Q064).

The firmware utilizes a dual-pin differential Capacitive Voltage Divider (CVD) charge-transfer topology on the onboard SW7 copper pad (PTC17 driving, bridging resistor R525 10 kΩ/4.7 kΩ, PTC16/ADC0_SE14 sensing, and external reference capacitor C533 10 pF). It is built with NXP Real Time Drivers (RTD 3.0.0) and defensive embedded C practices.

✦ Key Features

  • Bipolar Four-Phase Differential CVD: Alternates positive and negative precharge & charge-sharing phases, yielding ~2× differential physical signal gain while rejecting common-mode supply noise.
  • Multi-Frequency Spread-Spectrum Burst Acquisition (MFP): 16-bit Galois LFSR (0xB400) pseudo-random sample delay hopping across coprime delay counts {15, 23, 31} cycles to avoid EMI harmonic synchronization.
  • Cascaded Non-Linear Filtering Engine: 9-sample burst acquisition with Alpha-trimmed mean (rejecting highest/lowest 2 outliers) cascaded into a 1D Adaptive Scalar Kalman Filter (Q=0.35, R=1.0, α=0.75) with high-slew fast-path bypass.
  • 4-Zone Asymmetric Dynamic Baseline Tracking: Slew-rate bounded ambient drift tracking (+1.5 LSB/s / −2.0 LSB/s), approach freeze zone (0.4×TH), 15-second continuous contact timeout, and fast negative anomaly recovery (≤285 ms).
  • Rule-Based Temporal Envelope Feature Classifier: Lightweight heuristic decision tree extracting 4 time-domain envelope features (attack slope, dynamic SNR, normalized curvature variance, sustain ratio) with 3-step confidence hysteresis (0.64 trigger / 0.38 release).
  • Hardware Plausibility Diagnostics & Fail-Safe Interlock: Continuous monitoring of Short-to-GND (<300 LSB), Short-to-VDD (>3800 LSB), R525 bridging integrity, and ADC reference VREFH drift (±5%).
  • Hardware-Locked 15.0 ms Frame Synchronizer: ARM Cortex-M SysTick (48 MHz) for zero-jitter 66.7 Hz frame timing. ~195–215 µs per cycle (~1.4% CPU load).
  • Defensive Embedded C Architecture: 0 Bytes heap, timeout guards on all hardware polling loops, static stack <250 Bytes.

S32K144W 電容觸控演算法參考實作 (CVD & 規則式包絡分類器)

本專案為專為 恩智浦半導體 (NXP Semiconductors®) S32K144W 評估板 (XS32K14WEVB-Q064) 所設計的嵌入式電容觸控（CVD）演算法參考實作韌體。

韌體採用板載 SW7 銅箔電極上的雙腳位差動電荷轉移架構（PTC17 驅動、跨接電阻 R525 10kΩ/4.7kΩ、PTC16/ADC0_SE14 感測、基準電容 C533 10 pF）。系統基於 NXP RTD 3.0.0 與防禦性嵌入式 C 語言實踐構建。

✦ 核心特性 (Key Features)

  • 雙極性四相位差動 CVD：交替正向與反向預充電及電荷轉移，差動物理信號增益約 2×，自然抵消電源共模雜訊。
  • 多頻擴頻叢集採樣 (MFP)：16 位元 Galois LFSR (0xB400) 與互質延遲序列 {15, 23, 31} 週期進行採樣抖動，破除週期性 EMI 諧波同步鎖定。
  • 串聯式非線性濾波引擎：9 點叢集採樣經 Alpha-trimmed mean（剔除最高/最低各 2 個離群值）後，串聯一維自適應純量卡爾曼濾波器 (Q=0.35, R=1.0, α=0.75) 與大斜率快速旁路通道。
  • 四區段非對稱動態基線追蹤器：斜率限制環境漂移追蹤 (+1.5 LSB/s / −2.0 LSB/s)、接近凍結區 (0.4×TH)、15 秒長按超時重置、帶手開機快速自癒 (≤285 ms)。
  • 規則式時域包絡特徵分類器：輕量級啟發式決策樹提取 4 項時域特徵（起拍斜率、動態 SNR、曲率變異數、維持比率），配合 3 階信賴度滑動視窗遲滯 (0.64 觸發 / 0.38 釋放)。
  • 硬體合理性線上缺陷診斷與安全互鎖：即時監控接地短路 (<300 LSB)、電源短路 (>3800 LSB)、R525 跨接完整性、及 ADC 參考電壓 VREFH 漂移 (±5%)。
  • 硬體鎖定 15.0 ms 訊框同步器：ARM Cortex-M SysTick (48 MHz) 驅動 66.7 Hz 零抖動訊框，核心演算法耗時約 195~215 µs（約 1.4% CPU 負載）。
  • 防禦性嵌入式 C 架構：保證 0 Bytes 堆積記憶體、所有硬體輪詢迴圈皆有逾時保護、靜態堆疊預算 <250 Bytes。
